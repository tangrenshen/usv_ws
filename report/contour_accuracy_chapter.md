# 目标轮廓/尺寸精度分析

> 对应综合研究报告"环境感知模块"下"周围目标识别精度"相关内容，服务评分细则
> 指标#3（"虚拟场景中动态/静态目标的三维位置及轮廓形状误差，综合误差越小越好"）
> 与方案评审"技术可行性"（30分，"所提指标可实现性分析是否充分"）。本节结论：
> 已定量确认轮廓尺寸误差的分布规律及其成因，但经风险评估后判定当前条件下不宜
> 引入尺寸补偿，理由见第4节。

## 1. 方法

以立柱(pillar)作为主基准：立柱为固定半径0.8m的圆柱体，其XY方向包围盒
（1.6m×1.6m）在任意朝向下都不随本船-目标相对朝向变化而改变，是四类目标中唯一
不需要朝向修正、不受旋转膨胀效应干扰的类别，能直接、干净地反映检测本身的尺寸
收缩程度。方块(block, 2m×2m方形浮块)作为次要验证，额外引入基于GT朝向的
旋转修正（方形AABB随相对朝向变化，最多膨胀至√2倍）。浮球(buoy)因存在两种
物理尺寸不同的子类型（球形r=0.25m与套环形r=0.325m，直径相差约30%）且GT话题
与检测输出均不携带类型字段，无法确定具体某实例属于哪型，本轮不纳入——混入
未知30%量级的类型混淆会掩盖本来要精确测量的效应，测出的数字无法证实或证伪
任何结论。

验证链条复用了已有的epoch对齐、坐标变换（`world_to_boat`）与最大基数二分匹配
逻辑（`four_category_evaluator_v2.py`），未重新实现这条历史上最容易出错的部分。
为确认结论不依赖单次录制的偶然性，同一诊断脚本在三段独立录制（bag_09_03_17/
bag_09_08_35/bag_09_10_54，共约3分钟数据）上分别运行。

> **数据来源说明**：本节数字已更新为5次独立初始化仿真录制（对应评分细则"5次
> 不同初始化条件下的独立运行"的自建等价方案，见综合研究报告方法论章节）的
> 结果，取代早期基于3段历史录制的初步结果——旧结果的场景配置来源不明确，
> 不适合作为最终结论，此处不再引用旧数字。

## 2. 近距离(0-20m)：尺寸估计基本无偏，跨5次独立运行稳定

| 运行 | dx误差 |
|---|---:|
| run1 | -4.9% |
| run2 | +1.3% |
| run3 | +9.0% |
| run4 | +2.8% |
| run5 | -3.6% |

5次独立运行均在个位数百分比范围内波动，无系统性方向偏置(2次略偏小、3次略
偏大)。结论：近距离目标尺寸估计基本无偏，不需要修正。

## 3. 远距离(40m+)：系统性收缩约40-53%，已确认为几何遮挡而非采样稀疏

| 运行 | dx误差 |
|---|---:|
| run1 | -53.1% |
| run2 | -38.1% |
| run3 | -50.3% |
| run4 | -52.4% |
| run5 | -44.1% |

5次独立运行方向完全一致、量级稳定在-38%~-53%区间——是本次分析里跨场景
复现性最好的一档结论。

**机制已确认为几何性质，非采样稀疏**：按匹配到的cluster点数统计（不依赖任何
尺寸假设，是本诊断里最少假设的量），40m+桶的点数中位数常年在数十到上百量级，
远高于"个位数点、根本没测到"的采样失败特征。检测器能获取足够的点云覆盖，但
受限于近端面效应——只能观测到目标朝向本船一侧的表面，无法观测到背对本船一侧
和切向边缘，因此包围盒系统性小于目标真实直径（该效应的几何成因见硬件基础
章节第3节：Airy雷达半球面朝向决定了任意单路观测都只能覆盖目标朝向雷达一侧，
这一限制与安装朝向无关，是六路雷达联合覆盖设计本身要弥补、但无法完全消除的
局限）。这一区分很重要：若是采样稀疏，
补偿只能是统计外推，可靠性差；确认是几何遮挡后，理论上存在"按可见面推断完整
尺寸"的补偿路径，但本节第4条说明了为什么这一轮不实现它。

## 4. 中距离(20-40m)：偏差方向本身不稳定，不构成补偿依据

| 运行 | dx误差 |
|---|---:|
| run1 | -19.6% |
| run2 | -25.9% |
| run3 | +0.0% |
| run4 | +10.7% |
| run5 | +7.3% |

5次独立运行里，偏差**符号本身不一致**——2次为负(-19.6%、-25.9%)，1次接近
零，2次为正(+10.7%、+7.3%)。这比单纯"量级不稳定"更能说明问题：任何固定
方向的补偿系数（无论加大还是缩小），在另一部分场景下都会把误差推向反方向、
使结果比不补偿更差。这是本节所有发现里对"不做补偿"这一决定支撑力度最强的
证据——不是偏差量级的置信区间宽，而是连修正的方向都无法预先确定。

## 5. block的独立效应：旋转导致的部分遮挡，与距离效应正交

方块作为唯一验证过旋转修正的非圆形类别，额外表现出一个立柱结构上不可能出现
的效应：检测到的AABB随目标-本船相对朝向角度单调增长（20-40m桶按|相对朝向|
分层：0-10°时det_dx中位2.069m，10-20°时2.251m，20-30°时2.414m，30-45°时
2.452m），方向与"方形转45°时AABB应变大"的理论完全一致——这一单调性检验本身
排除了朝向变换实现有符号/约定错误的可能（错误的变换不会产生方向正确的单调
响应，这是比任何静态代码检查更有说服力的独立证据）。但观测到的增长速率明显
慢于纯几何理论值(0.38m实测 vs 0.8m理论，覆盖同样的角度区间)，与"近端面效应
同样会遮挡掉旋转后新暴露的远侧角点"一致，即距离和旋转是两个独立但会叠加的
收缩来源。这解释了为什么非圆形目标(block/boat)的补偿必然比立柱更复杂——需要
同时用距离和相对朝向两个维度建模，且相对朝向依赖目标GT朝向，而比测现场只能
用检测器自身PCA解出的yaw替代（该yaw来自同一批本就有缺角的点云，用它反过来
修正同一批点云的尺寸，存在自我验证的风险，需要先独立验证PCA yaw本身的可信度，
本轮未做）。

## 6. 工程判断：本轮不引入尺寸补偿

近距离(0-20m)不需要补偿。中距离(20-40m)的偏差**连方向都不稳定**（第4节），
缺乏可靠的补偿系数基础——这不是数据不够多的问题，是这个距离段本身对场景
配置的敏感度超过了单一系数能覆盖的范围。远距离(40m+)虽然偏差量级本身可信
（5次独立随机世界初始化，方向和量级都高度一致），但判定不适合补偿，原因是
运行时补偿的风险不对称：

1. **补偿倍率高，出错代价随倍率放大**：40m+平均收缩约40-53%，意味着补偿需要
   接近2倍放大系数；该区间偏差在5次完全独立的随机世界初始化下已有约15个
   百分点的自然波动(-38%~-53%)——这还只是场景配置本身的变化，比测的5次
   独立运行在此基础上还会叠加随机外参扰动，实际波动大概率更大。系数选取的
   绝对误差会被2倍放大系数等比例放大到最终尺寸上，可能比不补偿更差。
2. **补偿对象本身是全流程里最不可信的一段**：40m+同时是已知遗漏率最高、
   噪声占比最高的距离段（`boat_far_forward_reject`即因此对boat类别在该距离段
   直接拒绝而非尝试修正）。给一批本来就稀疏、可能混有误检的远距目标叠加一个
   高倍率的激进修正，是在不确定性最大的地方做最激进的操作，不符合稳健设计
   原则。

## 7. 本节结论对应的评分价值

本节没有产出一个补偿系数，但产出了一份可以直接支撑"技术可行性"评分的定量
分析：轮廓误差的来源、量级、随距离/朝向的变化规律、以及为什么在当前条件下
主动选择不做补偿——这是一个经过风险评估的工程判断，而不是"没想到"或
"没时间做"。诊断工具本身（`contour_xy_diagnostic.py`及扩展后的`boat_logger.py`）
已经过三段独立录制验证，若后续比测条件改变（如证实中/远距离检测本身更可信、
或补充了比测环境的空间点云密度信息），可直接复用，不需要重新搭建。
